# HOW TO RECREATE SQL IN CASE OF DATA CORRUPTION 

1 - LAUNCH SCRIPT CREATE_ALL_TABLE TO RECREATE STRUCTURE

2 - LAUNCH SCRIPT_DATABASE_HISTORIC TO GET ALL THE DATA FROM THE DATASTORE IN THE SQL (MIGHT TAKE A LOT OF TIME : USE VM ON APPENGINE)

3 - TO GET DATA FROM BEFORE 2017 (BEFORE COMMCARE) LAUNCH SCRIPT_HISTORICNOTONCOMMCARE
